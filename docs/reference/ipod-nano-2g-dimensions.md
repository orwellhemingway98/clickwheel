# iPod nano (2nd generation): reference dimensions

All values are in millimetres, for the front face, upright.

**Source.** Apple, *Accessory Design Guidelines for Apple Devices*, Release R4
(2017-09-21), §16.62, Figure 16-67, "iPod nano 2nd gen. Dimensional Drawing"
(drawn sideways). Tolerances: X.X ±0.4, X.XX ±0.20. Values marked *measured* were
read off the drawing at ≈ 5.13 px/mm (display scale), checked against the labelled
90.00 length and 40.00 width.

| Feature | Value | Notes |
|---|---|---|
| Body | 40.00 × 90.00 | labelled; aluminium tube with square ends |
| Depth | 6.50 | labelled |
| Top edge step | 0.36 | labelled |
| Rounded side bands | ≈ 4.3 each side | *measured*: lines along the full length |
| Display window | 31.62 × 24.04, centred horizontally | labelled |
| Window top | 4.25 below the top edge | labelled |
| Click wheel | Ø 30.16, centred horizontally | labelled |
| Wheel centre | 31.75 above the bottom edge | labelled |
| Center button | Ø 13.11 | labelled |
| LCD | 176 × 132 px at ≈ 0.16 mm | as the nano 1G |
