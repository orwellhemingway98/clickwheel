# iPod nano (1st generation): reference dimensions

All values are in millimetres, for the front face, upright.

**Source.** Apple, *Accessory Design Guidelines for Apple Devices*, Release R4
(2017-09-21), §16.63, Figure 16-68, "iPod nano Dimensional Drawing" (drawn
sideways). Tolerances: X.X ±0.4, X.XX ±0.20. Values marked *measured* were read
off the to-scale drawing at ≈ 6.06 px/mm (a 3× render), a scale checked against
the labelled 90.00 length, 40.00 width and 22.18 window.

| Feature | Value | Notes |
|---|---|---|
| Body | 40.00 × 90.00 | labelled |
| Depth | 6.90 | labelled |
| Top edge step | 0.30 | labelled |
| Body corner radius | ≈ 3.0 | *measured, rough* |
| Polished edge seen from the front | ≈ 0.6–0.8 | *measured*: a second outline just inside the body |
| Display window | 29.57 × 22.18, centred horizontally | labelled |
| Window centre | 73.64 above the bottom edge | labelled; window top 5.27 below the top |
| Click wheel | Ø 30.23, centred horizontally | labelled |
| Wheel centre | 31.79 above the bottom edge | labelled |
| Center button | Ø ≈ 13.0 | *measured* from two chords |
| LCD | 1.5″ colour, 176 × 132 px at ≈ 0.16 mm (28.2 × 21.1) | sized to sit inside the window |
