# iPod (4th generation): reference dimensions

All values are in millimetres, for the front face, upright.

**Source.** Apple, *Accessory Design Guidelines for Apple Devices*, Release R4
(2017-09-21), §16.68, Figure 16-73, "iPod 4th gen. Dimensional Drawing" (drawn
sideways). Tolerances: X.X ±0.4, X.XX ±0.20. Values marked *measured* were read
off the to-scale drawing at ≈ 6.13 px/mm (a 3× render), a scale checked against
the labelled 103.50 length and 71.04 wheel position.

| Feature | Value | Notes |
|---|---|---|
| Body | 61.80 × 103.50 | labelled |
| Depth | 14.60 (20 GB), 17.60 (40 GB) | labelled |
| Top edge step | 0.34 | labelled |
| Flat front face (inside the rounded edges) | ≈ 5.7 from the sides, ≈ 5.6 from the top, ≈ 6.0 from the bottom | *measured* |
| Body corner radius | ≈ 6.0 | not labelled; as the 3G |
| Display window | 34.00 tall (labelled) × ≈ 41.5 wide, centred horizontally | width *measured* |
| Window centre | 23.59 below the top edge | labelled; window top 6.59 below the top |
| LCD active area (dashed) | ≈ 38.2 × 30.5 | *measured*: 160 × 128 px at 0.24 mm |
| Click wheel | Ø 42.06, centred horizontally | labelled |
| Wheel centre | 71.04 below the top edge (32.46 above the bottom) | labelled |
| Center button | Ø ≈ 13.9 | *measured* |
