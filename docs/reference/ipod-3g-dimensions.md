# iPod (3rd generation): reference dimensions

All values are in millimetres, for the front face, upright.

**Source.** Apple, *Accessory Design Guidelines for Apple Devices*, Release R4
(2017-09-21), §16.69, Figure 16-74, "iPod 3rd gen. Dimensional Drawing".
Tolerances on that drawing: X.X ±0.4, X.XX ±0.20.

Values marked *measured* are not labelled on the drawing. They were measured from
the to-scale drawing at 12.15 px/mm, a scale checked against the labelled 61.80 mm
width and 40.29 mm window.

| Feature | Value | Notes |
|---|---|---|
| Body | 61.80 × 103.49 | labelled |
| Depth | 15.70 (10–15 GB), 18.70 (30 GB) | labelled |
| Top edge step | 0.41 | labelled |
| Body corner radius | ≈ 6.0 | *measured, rough*; the edges are strongly rounded |
| Flat front face (inside the rounded edges) | ≈ 50.0 wide, ≈ 5.2 from top, ≈ 7.2 from bottom, corner ≈ 3.4 | *measured* |
| Display window | 40.29 × 32.61, centred horizontally | labelled |
| Window centre | 23.54 below the top edge | labelled; this puts the window top 7.24 below the top edge |
| Touch buttons | four, Ø 10.90, in a row | labelled ("TYP") |
| Button row centre | 49.91 below the top edge | labelled |
| Button centres, horizontal | 30.90 ± 6.65 and 30.90 ± 19.95 (13.3 apart) | *measured*; symmetric |
| Touch wheel | Ø 38.70, centred horizontally | labelled |
| Wheel centre | 77.08 below the top edge (26.41 above the bottom) | labelled |
| Center button | Ø 14.50 | labelled |
