# iPod (5th generation) 30 GB: reference dimensions

All values are in millimetres, for the front face, upright.

**Source:** Apple, *Accessory Design Guidelines for Apple Devices*, Release R4
(2017-09-21), §16.67, Figure 16-72, "iPod 5th gen. 30GB Dimensional Drawing"
(Apple drawing iPod10-12 30 GB). Tolerances on that drawing: X.X ±0.4,
X.XX ±0.20.

Values marked *measured* are not labelled on the drawing. They were measured from
the to-scale drawing rendered at 12.13 px/mm. That scale was checked against the
labelled body width, window and wheel, which all agree within 0.5%.

| Feature | Value | Notes |
|---|---|---|
| Body width | 61.80 | labelled |
| Body height | 103.50 | labelled |
| Body depth | 11.00 | labelled (60/80 GB model: 14.0) |
| Body corner radius | ≈ 6.8 | *measured*: a circle fit to the outline (82 px) |
| Top edge step | 0.39 | labelled; the front face sits slightly below the back shell |
| Display window | 52.42 × 39.94 | labelled; centred horizontally (30.90 from each side) |
| Display window centre | 78.84 above bottom edge | labelled; this puts the window's top 4.69 below the top edge |
| Display window corner radius | ≈ 1.0 | *measured* |
| Window margins | 4.69 top, left and right | derived: one even border around the screen |
| LCD active area | 49.92 × 37.44 | 320 × 240 px at 0.156 mm dot pitch (Apple spec) |
| Click wheel diameter | 38.10 | labelled |
| Click wheel centre | 30.44 above bottom edge | labelled; centred horizontally |
| Gap between window and wheel | 9.38 | derived |
| Wheel to bottom edge | 11.39 | derived |
| Center button diameter | ≈ 13.7 | *measured*: 166 px, 0.36 × the wheel diameter |
