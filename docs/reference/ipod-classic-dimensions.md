# iPod classic (2007): reference dimensions

All values are in millimetres, for the front face, upright.

**Source.** Apple, *Accessory Design Guidelines for Apple Devices*, Release R4
(2017-09-21), §16.65, Figure 16-70, "iPod classic 80GB Dimensional Drawing"
(drawn sideways; §16.64 is the thicker 160 GB). Tolerances: X.X ±0.4. Values
marked *measured* were read off the drawing at ≈ 6.13 px/mm (a 3× render),
checked against the labelled 103.5 length and 24.7 window centre.

| Feature | Value | Notes |
|---|---|---|
| Body | 61.8 × 103.5 | labelled |
| Depth | 10.5 | labelled (80 GB) |
| Top edge step | 0.4 | labelled |
| Display window | 52.0 × 39.5, centred horizontally | labelled |
| Window centre | 24.7 below the top edge | labelled; window top 4.95 |
| Click wheel | Ø 38.0, centred horizontally | labelled |
| Wheel centre | 30.4 above the bottom edge | labelled |
| Center button | Ø 13.7 | labelled |
| Steel edge seen from the front | ≈ 1.0 | *measured, rough* |
| Corners | as the 5G (≈ 6.8) | the same outline |
| LCD | 2.5″ 320 × 240, as the 5G | |
