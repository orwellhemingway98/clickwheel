# iPod photo: reference dimensions

All values are in millimetres, for the front face, upright.

**Source.** Apple, *Accessory Design Guidelines for Apple Devices*, Release R4
(2017-09-21), §16.71, Figure 16-76, "iPod photo Dimensional Drawing" (drawn
sideways). The thinner 2005 "iPod photo 30GB/60GB" (§16.70) shares the front.
Apple's "Identify your iPod model": the iPod photo and the iPod with color
display are functionally and visually identical.
