# iPod mini: reference dimensions

All values are in millimetres, for the front face, upright.

**Source.** Apple, *Accessory Design Guidelines for Apple Devices*, Release R4
(2017-09-21), §16.76, Figure 16-82, "iPod mini Dimensional Drawing".
Tolerances on that drawing: X.X ±0.4, X.XX ±0.20. Values marked *measured* are
not labelled; they were read off the to-scale drawing (≈ 9.17 px/mm in the crop,
checked against the labelled 51.45 width).

| Feature | Value | Notes |
|---|---|---|
| Body | 51.45 × 91.66 | labelled; square corners in front view (aluminium tube with flat end caps) |
| Depth | 13.80 | labelled |
| Top edge step | 0.40 | labelled |
| Rounded side bands | ≈ 8.3 each side | *measured*: the tube curves away; flat front ≈ 34.9 wide |
| Display window | 33.85 × 26.19, centred horizontally | labelled |
| Window centre | 72.29 above the bottom edge | labelled; window top 6.28 below the top edge |
| Window corner | ≈ 0.5 | *measured, rough* |
| Click wheel | Ø 37.95, centred horizontally | labelled |
| Wheel centre | 28.75 above the bottom edge | labelled |
| Center button | Ø 12.50 | labelled |
