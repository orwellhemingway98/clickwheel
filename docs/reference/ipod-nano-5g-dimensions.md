# iPod nano (5th generation): reference dimensions

All values are in millimetres, for the front face, upright.

**Source.** Apple, *Accessory Design Guidelines for Apple Devices*, Release R4
(2017-09-21), §16.59, Figure 16-64, "iPod nano 5th gen. Dimensional Drawing"
(drawn sideways). Tolerances: X.X ±0.4.
