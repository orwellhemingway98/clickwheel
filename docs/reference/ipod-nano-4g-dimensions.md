# iPod nano (4th generation): reference dimensions

All values are in millimetres, for the front face, upright.

**Source.** Apple, *Accessory Design Guidelines for Apple Devices*, Release R4
(2017-09-21), §16.60, Figure 16-65, "iPod nano 4th gen. Dimensional Drawing"
(drawn sideways). Tolerances: X.X ±0.4. Values marked *estimated* are not labelled.

| Feature | Value | Notes |
|---|---|---|
| Body | 38.7 × 90.7 | labelled |
| Depth | 6.2 | labelled; elliptical cross-section |
| Top edge step | 0.4 | labelled |
| Body corner radius | ≈ 1.0 | *estimated*: nearly square in the front view |
| Curved sides | ≈ 5 each side | *estimated* from the end view |
| Display window | 29.9 × 39.8 (portrait), centred horizontally | labelled |
| Window centre | 24.3 below the top edge | labelled; window top 4.4 |
| Click wheel | Ø 28.5, centred horizontally | labelled |
| Wheel centre | 23.3 above the bottom edge | labelled |
| Center button | Ø 13.2 | labelled |
| LCD | 2″ 240 × 320 portrait at 0.124 mm (29.76 × 39.68) | fills the window |
