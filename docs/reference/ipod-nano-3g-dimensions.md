# iPod nano (3rd generation): reference dimensions

All values are in millimetres, for the front face, upright.

**Source.** Apple, *Accessory Design Guidelines for Apple Devices*, Release R4
(2017-09-21), §16.61, Figure 16-66, "iPod nano 3rd gen. Dimensional Drawing"
(drawn sideways). Tolerances: X.X ±0.4. Values marked *estimated* are not
labelled and were judged from the drawing (≈ 2.58 px/mm on the page).

| Feature | Value | Notes |
|---|---|---|
| Body | 52.3 × 69.8 | labelled (wide × tall) |
| Depth | 6.5 | labelled |
| Top edge step | 0.2 | labelled |
| Body corner radius | ≈ 4.5 | *estimated* |
| Steel edge seen from the front | ≈ 0.8 | *estimated*; aluminium plate in a steel shell, as the classic |
| Display window | 39.8 × 29.9, centred horizontally | labelled |
| Window centre | 20.2 below the top edge | labelled; window top 5.25 |
| Click wheel | Ø 27.0, centred horizontally | labelled |
| Wheel centre | 17.6 above the bottom edge | labelled |
| Center button | Ø 13.2 | labelled |
| LCD | 2″ 320 × 240 at ≈ 0.12 mm (38.4 × 28.8) | sized to sit inside the window |
